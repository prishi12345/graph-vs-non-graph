Graph vs Non-Graph Learning

This project is a simple comparative study to understand whether using graph structure improves learning performance.

I compare:
- A baseline non-graph model (MLP)  
- A graph-based model (GCN)

Both models are trained on the same dataset (Cora) to observe differences in accuracy and learning behavior.

The goal of this project is to learn graph neural networks step by step and understand when graph-based learning is useful.
